# Git Watch Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Show a menu bar warning when a default branch on this Mac or on an SSH host has commits that are not on its remote.

**Architecture:** One POSIX script finds repos under the roots of a machine and prints one tab-separated line per repo. This Mac runs it with `/bin/sh -s`. A remote host runs it with `ssh -o BatchMode=yes <host> sh -s`. `GitWatchCoordinator` (owned by `AppCore`) scans on a timer and on wake, and owns a second `NSStatusItem` that exists only while a repo is at risk.

**Tech Stack:** Swift 6, AppKit `NSStatusItem`, SwiftUI settings pane, `Process`, POSIX `sh`, `find`, `git`, OpenSSH.

**Spec:** [docs/superpowers/specs/2026-10-10-git-watch-design.md](../specs/2026-10-10-git-watch-design.md)

**Commits:** The user commits only on request. Do not commit at the end of a task. Report the task as done and wait.

```swift
import Foundation

/// What a default branch holds that its remote does not. Raw values are the script's spellings.
enum GitWatchRepoState: String, Sendable {
    case ahead, noRemote, unpushed, clean, error

    var isAtRisk: Bool { self == .ahead || self == .noRemote || self == .unpushed }
}

struct GitWatchRepo: Hashable, Sendable {
    let path: String
    let branch: String
    let state: GitWatchRepoState
    /// Commits missing from the upstream; with no upstream at all, every commit on the branch.
    let commitCount: Int

    var name: String { URL(filePath: path).lastPathComponent }

    var summary: String {
        switch state {
        case .ahead: "\(branch) ↑\(commitCount)"
        case .noRemote: "\(branch), no remote"
        case .unpushed: "\(branch), never pushed"
        case .clean: branch
        case .error: "unreadable"
        }
    }
}
```

- [ ] **Step 5: Write `GitWatchReport.swift`**

```swift
import Foundation

/// One machine's scan, parsed from the tab-separated lines `GitWatchScript` prints.
struct GitWatchReport: Equatable, Sendable {
    var repos: [GitWatchRepo] = []
    var missingRoots: [String] = []
    var unparsedLineCount = 0

    init(parsing output: String) {
        for line in output.split(separator: "\n") {
            let fields = line.split(separator: "\t", omittingEmptySubsequences: false).map(String.init)
            switch fields.first {
            case "repo"? where fields.count == 5:
                guard let state = GitWatchRepoState(rawValue: fields[3]), let count = Int(fields[4])
                else {
                    unparsedLineCount += 1
                    continue
                }
                repos.append(
                    GitWatchRepo(path: fields[1], branch: fields[2], state: state, commitCount: count))
            case "missingRoot"? where fields.count == 2:
                missingRoots.append(fields[1])
            default:
                unparsedLineCount += 1
            }
        }
        repos.sort { $0.path < $1.path }
    }

    var atRisk: [GitWatchRepo] { repos.filter(\.state.isAtRisk) }
}
```

- [ ] **Step 3: Write `GitWatchMachine.swift`**

```swift
import Foundation

/// A machine Git Watch scans. The host is its identity, and an empty host is this Mac.
struct GitWatchMachine: Codable, Hashable, Sendable, Identifiable {
    var host: String
    var roots: [String]
    /// Repo paths exactly as the scan prints them.
    var ignoredPaths: [String] = []

    var id: String { host }
    var isLocal: Bool { host.isEmpty }
    var displayName: String { isLocal ? "This Mac" : host }

    static let thisMac = GitWatchMachine(host: "", roots: ["~/dev"])

    /// This Mac first and once, then each remote host once; a host ssh could read as an option goes.
    static func normalize(_ machines: [GitWatchMachine]) -> [GitWatchMachine] {
        var seen: Set<String> = []
        var result: [GitWatchMachine] = []
        for var machine in machines {
            machine.host = machine.host.trimmingCharacters(in: .whitespaces)
            guard !machine.host.hasPrefix("-"), !machine.host.contains(where: \.isWhitespace),
                seen.insert(machine.host).inserted
            else { continue }
            result.append(machine)
        }
        if let local = result.firstIndex(where: \.isLocal) {
            result.insert(result.remove(at: local), at: 0)
        } else {
            result.insert(thisMac, at: 0)
        }
        return result
    }

    /// The process that reads `GitWatchScript` on stdin.
    var shellCommand: (executable: String, arguments: [String]) {
        isLocal
            ? ("/bin/sh", ["-s"])
            : ("/usr/bin/ssh", ["-o", "BatchMode=yes", "-o", "ConnectTimeout=10", host, "sh -s"])
    }

    /// What the menu copies for a remote repo: a login shell that starts in the repo folder.
    func terminalCommand(for path: String) -> String {
        let remote = "cd \(GitWatchScript.quoted(path)) && exec \"$SHELL\" -l"
        return "ssh -t \(host) \(GitWatchScript.quoted(remote))"
    }
}
```

- [ ] **Step 4: Write `GitWatchScript.swift`**

The script body was checked by hand against repos in each state before this plan was written. Keep it POSIX: a remote host may have only `dash` or BusyBox `sh`.

```swift
import Foundation

/// The POSIX script every machine runs, so this Mac and a remote host share one code path.
enum GitWatchScript {
    static let skippedFolders = [
        "node_modules", ".build", "vendor", "Library", "DerivedData", "Pods", ".cache"
    ]

    static func make(roots: [String]) -> String {
        let skip = skippedFolders.map { "-name \(quoted($0))" }.joined(separator: " -o ")
        let scans = roots.map { "scan_root \(quoted($0))\n" }.joined()
        return body.replacingOccurrences(of: "@SKIP@", with: skip) + scans + "exit 0\n"
    }

    /// Single quotes pass every byte literally; an embedded quote closes, escapes and reopens them.
    static func quoted(_ text: String) -> String {
        "'" + text.replacingOccurrences(of: "'", with: #"'\''"#) + "'"
    }

    private static let body = #"""
        export GIT_OPTIONAL_LOCKS=0
        report() { printf 'repo\t%s\t%s\t%s\t%s\n' "$1" "$2" "$3" "$4"; }
        check_repo() {
          repo=$1
          if ! git -C "$repo" rev-parse --verify --quiet HEAD >/dev/null 2>&1; then
            report "$repo" "" clean 0; return
          fi
          branch=$(git -C "$repo" symbolic-ref --quiet --short refs/remotes/origin/HEAD 2>/dev/null)
          branch=${branch#origin/}
          if [ -z "$branch" ]; then
            for candidate in main master; do
              if git -C "$repo" show-ref --verify --quiet "refs/heads/$candidate"; then
                branch=$candidate; break
              fi
            done
          fi
          if [ -z "$branch" ]; then
            branch=$(git -C "$repo" symbolic-ref --quiet --short HEAD 2>/dev/null)
          fi
          if [ -z "$branch" ]; then report "$repo" "" error 0; return; fi
          if ! git -C "$repo" show-ref --verify --quiet "refs/heads/$branch"; then
            report "$repo" "$branch" clean 0; return
          fi
          remotes=$(git -C "$repo" remote)
          if [ -z "$remotes" ]; then
            report "$repo" "$branch" noRemote "$(git -C "$repo" rev-list --count "$branch")"; return
          fi
          upstream=$(git -C "$repo" rev-parse --abbrev-ref --symbolic-full-name "$branch@{upstream}" 2>/dev/null)
          if [ -z "$upstream" ]; then
            for remote in $remotes; do
              if git -C "$repo" show-ref --verify --quiet "refs/remotes/$remote/$branch"; then
                upstream=$remote/$branch; break
              fi
            done
          fi
          if [ -z "$upstream" ]; then
            report "$repo" "$branch" unpushed "$(git -C "$repo" rev-list --count "$branch")"; return
          fi
          if ! ahead=$(git -C "$repo" rev-list --count "$upstream..$branch" 2>/dev/null); then
            report "$repo" "$branch" error 0; return
          fi
          if [ "$ahead" -gt 0 ]; then
            report "$repo" "$branch" ahead "$ahead"
          else
            report "$repo" "$branch" clean 0
          fi
        }
        scan_root() {
          root=$1
          case $root in "~") root=$HOME ;; "~/"*) root=$HOME/${root#"~/"} ;; esac
          if [ ! -d "$root" ]; then printf 'missingRoot\t%s\n' "$root"; return; fi
          find "$root" \( @SKIP@ \) -prune -o -name .git -prune -type d -print 2>/dev/null |
            while IFS= read -r gitdir; do check_repo "${gitdir%/.git}"; done
        }

        """#
}
```

Notes for the engineer:
- `-name .git -prune -type d -print` prints a `.git` folder and stops there. A `.git` file (a worktree or a submodule) fails `-type d`, so it is not reported twice.
- The `"$branch@{upstream}"` string is inside a raw string, so Swift does not read `@{` or `\t`.

- [ ] **Step 4: Write `GitWatchScanner.swift`**

This follows `ClipboardTextWorker`: blocking reads go on a private queue, never on the cooperative pool. stdout and stderr are read at the same time, so a full stderr pipe cannot stall the child.

```swift
import Foundation

/// Runs `GitWatchScript` on one machine and parses what it prints.
nonisolated enum GitWatchScanner {
    /// The pipe reads and the exit wait block, so they stay off the cooperative pool.
    private static let queue = DispatchQueue(
        label: "com.gstark.perch.git-watch", qos: .utility, attributes: .concurrent)

    static func scan(
        _ machine: GitWatchMachine, timeout: Duration = .seconds(60)
    ) async -> Result<GitWatchReport, GitWatchFailure> {
        let command = machine.shellCommand
        let process = Process()
        let input = Pipe()
        let output = Pipe()
        let errors = Pipe()
        process.executableURL = URL(filePath: command.executable)
        process.arguments = command.arguments
        process.standardInput = input
        process.standardOutput = output
        process.standardError = errors
        // An ssh that exits before reading stdin would otherwise kill Perch with SIGPIPE.
        _ = fcntl(input.fileHandleForWriting.fileDescriptor, F_SETNOSIGPIPE, 1)
        guard let exit = try? process.runObservingExit() else { return .failure(.launch) }
        let deadline = Task.detached { () -> Bool in
            do { try await Task.sleep(for: timeout) } catch { return false }
            terminate(process)
            return true
        }
        let (stdout, stderr) = await withTaskCancellationHandler {
            let script = Data(GitWatchScript.make(roots: machine.roots).utf8)
            try? input.fileHandleForWriting.write(contentsOf: script)
            try? input.fileHandleForWriting.close()
            async let stdout = readAll(output)
            async let stderr = readAll(errors)
            return await (stdout, stderr)
        } onCancel: {
            terminate(process)
        }
        await blocking { exit.wait() }
        deadline.cancel()
        if await deadline.value { return .failure(.timedOut) }
        guard process.terminationStatus == 0 else {
            let message = String(decoding: stderr, as: UTF8.self)
                .split(whereSeparator: \.isNewline).last.map(String.init) ?? ""
            return .failure(.exited(message: message))
        }
        return .success(GitWatchReport(parsing: String(decoding: stdout, as: UTF8.self)))
    }

    private static func readAll(_ pipe: Pipe) async -> Data {
        await blocking { (try? pipe.fileHandleForReading.readToEnd()) ?? Data() }
    }

    private static func blocking<Value: Sendable>(
        _ work: @escaping @Sendable () -> Value
    ) async -> Value {
        await withCheckedContinuation { continuation in
            queue.async { continuation.resume(returning: work()) }
        }
    }

    /// `terminate()` traps on a process that never launched, so the state has to be asked first.
    private static func terminate(_ process: Process) {
        if process.isRunning { process.terminate() }
    }
}
```

```swift
import AppKit

/// Scans every machine on a schedule and on wake, and keeps the newest report for each host.
@MainActor
@Observable
final class GitWatchCoordinator {
    struct MachineStatus {
        var report: GitWatchReport?
        var scannedAt: Date?
        var failure: GitWatchFailure?

        /// A failed scan keeps the last report: work at risk stays at risk until a scan clears it.
        var isStale: Bool { failure != nil && report != nil }
    }

    private static let interval: Duration = .seconds(600)

    private(set) var statuses: [String: MachineStatus] = [:]
    private(set) var isScanning = false
    /// Environment injection and settings only — never for state this type owns.
    @ObservationIgnored private unowned let core: AppCore
    @ObservationIgnored private var schedule: Task<Void, Never>?
    @ObservationIgnored private var wakeToken: NotificationCenter.ObservationToken?
    @ObservationIgnored private lazy var statusItem = GitWatchStatusItem(coordinator: self)
    private var settings: AppSettings { core.settings }

    init(core: AppCore) {
        self.core = core
    }

    func start() {
        schedule = Task { [weak self] in
            while !Task.isCancelled {
                await self?.scanAll()
                try? await Task.sleep(for: Self.interval)
            }
        }
        wakeToken = NSWorkspace.shared.notificationCenter.addObserver(
            of: NSWorkspace.shared, for: .didWake
        ) { [weak self] _ in
            Task { await self?.scanAll() }
        }
    }

    /// Each machine with repos at risk, ignored repos left out, in Settings order.
    var atRisk: [(machine: GitWatchMachine, repos: [GitWatchRepo])] {
        settings.gitWatchMachines.compactMap { machine in
            let repos = (statuses[machine.host]?.report?.atRisk ?? [])
                .filter { !machine.ignoredPaths.contains($0.path) }
            return repos.isEmpty ? nil : (machine, repos)
        }
    }

    func scanAll() async {
        guard !isScanning else { return }
        isScanning = true
        defer { isScanning = false }
        let machines = settings.gitWatchMachines.filter { !$0.roots.isEmpty }
        await withTaskGroup(of: (String, Result<GitWatchReport, GitWatchFailure>).self) { group in
            for machine in machines {
                group.addTask { (machine.host, await GitWatchScanner.scan(machine)) }
            }
            for await (host, result) in group {
                record(result, for: host)
            }
        }
        let hosts = Set(settings.gitWatchMachines.map(\.host))
        statuses = statuses.filter { hosts.contains($0.key) }
        refreshStatusItem()
    }

    /// The Settings button and the menu's Scan Now: the user started it, so a HUD reports it.
    func scanNow() async {
        guard !isScanning else { return }
        await scanAll()
        let count = atRisk.reduce(0) { $0 + $1.repos.count }
        let failed = statuses.values.filter { $0.failure != nil }.count
        if failed > 0 {
            core.showMessage("\(failed) machine(s) could not be scanned", tone: .danger)
        } else if count > 0 {
            core.showMessage("\(count) repo(s) with unpushed commits", tone: .neutral)
        } else {
            core.showMessage("Everything is pushed")
        }
    }

    func refreshStatusItem() {
        statusItem.update(count: atRisk.reduce(0) { $0 + $1.repos.count })
    }

    func open(_ repo: GitWatchRepo, on machine: GitWatchMachine) {
        guard !machine.isLocal else {
            NSWorkspace.shared.open(URL(filePath: repo.path, directoryHint: .isDirectory))
            return
        }
        NSPasteboard.general.clearContents()
        NSPasteboard.general.setString(machine.terminalCommand(for: repo.path), forType: .string)
        core.showMessage("Copied an ssh command for \(repo.name)")
    }

    func showSettings() {
        core.settingsCoordinator.showSettings(tab: .gitWatch)
    }

    // MARK: - Machines

    func updateMachine(_ host: String, _ change: (inout GitWatchMachine) -> Void) {
        guard let index = settings.gitWatchMachines.firstIndex(where: { $0.host == host }) else { return }
        change(&settings.gitWatchMachines[index])
    }

    /// False when the host is empty, unsafe, or already listed.
    @discardableResult
    func addMachine(host: String) -> Bool {
        let before = settings.gitWatchMachines
        let after = GitWatchMachine.normalize(before + [GitWatchMachine(host: host, roots: ["~/dev"])])
        guard after.count > before.count else { return false }
        settings.gitWatchMachines = after
        Task { await scanAll() }
        return true
    }

    func removeMachine(host: String) {
        guard !host.isEmpty else { return }
        settings.gitWatchMachines.removeAll { $0.host == host }
        statuses[host] = nil
    }

    func ignore(_ path: String, on host: String) {
        updateMachine(host) { $0.ignoredPaths.append(path) }
    }

    func unignore(_ path: String, on host: String) {
        updateMachine(host) { $0.ignoredPaths.removeAll { $0 == path } }
    }

    private func record(_ result: Result<GitWatchReport, GitWatchFailure>, for host: String) {
        var status = statuses[host] ?? MachineStatus()
        switch result {
        case .success(let report):
            status.report = report
            status.failure = nil
        case .failure(let failure):
            status.failure = failure
        }
        status.scannedAt = .now
        statuses[host] = status
    }
}
```

```markdown
# Git Watch

A menu bar warning for local git work that could be lost. Git Watch scans this Mac and SSH hosts
for repositories. An icon with a count appears while a default branch has commits that are not on
its remote. Settings › Git Watch lists the machines and their roots.

## Invariants

- **One script for every machine.** `GitWatchScript` is POSIX `sh`. This Mac runs it with
  `/bin/sh -s`, and a remote host runs it with `ssh -o BatchMode=yes <host> sh -s`. Only
  `GitWatchMachine.shellCommand` knows the difference.
- **Perch never changes a repository.** The script runs no `fetch`, `push` or `gc`, and sets
  `GIT_OPTIONAL_LOCKS=0` so that `git` does not write the index.
- **A remote scan never prompts.** `BatchMode=yes` turns a password or host-key question into a
  failure, which Settings shows. SSH trust stays in `~/.ssh`.
- **A failed scan keeps the last report.** The menu marks it `(stale)`. Work at risk stays at risk
  until a scan says otherwise.
- **The icon exists only while something is at risk.** `GitWatchStatusItem` removes its
  `NSStatusItem` at a count of zero, and "Show in menu bar" does not affect it.
- **The parsing stays in `Model/`.** `Tests/git-watch-test.swift` compiles `Model/` and the scanner,
  and runs the real script against repos it creates in a temporary folder.

## States

| State | Condition | At risk |
| --- | --- | --- |
| `ahead` | The upstream lacks commits that the branch has. | Yes |
| `noRemote` | The repo has no remote. | Yes |
| `unpushed` | A remote exists, but the branch has no upstream and no `<remote>/<branch>`. | Yes |
| `clean` | Nothing to push, or the repo has no commits yet. | No |
| `error` | `git` failed, or no default branch was found. | No |

The default branch is the one `origin/HEAD` names, then `main`, then `master`, then the checked-out
branch.

## Freshness

Git Watch compares with the remote-tracking ref and never fetches. A push from the same clone moves
that ref, so the warning clears at the next scan. A push of the same commits from a different clone
does not move it. That clone shows as `ahead` until you fetch in it.

## Schedule

A scan runs at launch, every 10 minutes, after the Mac wakes, and on **Scan Now**. All machines scan
at the same time, and a scan has a 60-second limit. Results stay in memory.

## The menu

A local row opens the folder in Finder. A remote row copies `ssh -t <host> 'cd <path> && exec
"$SHELL" -l'`. Holding Option turns each row into **Ignore <name>**. Settings lists the ignored repos
of each machine.

## Requirements

- This Mac needs `/usr/bin/git`, which the Xcode command line tools provide.
- A remote host needs `sh`, `find` and `git`, and an SSH key that it accepts with no prompt.
```
